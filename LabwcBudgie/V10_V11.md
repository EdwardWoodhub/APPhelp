# 2026.08.27

Ubuntu Budgie 博客《The Road to Budgie 11》的核心规划与实际版本现状。文章阐明，Budgie 10.10 完成了全面的 Wayland 迁移并作为 10 系列的收官版本正式进入维护模式，开发重心全面转向下一代 **Budgie 11**。作为彻底重构的下一代桌面，Budgie 11 放弃了旧有的 GTK3/Vala 架构，全面转向 **Qt6 + C++/QML 与 KDE Frameworks**，并基于 Mir/Miriway 构建独立的 **Magpie 原生 Wayland 合成器**；其核心采用“协议优先”与模块化解耦设计，划分为负责系统/显示/通知等底层集成的 **Budgie Core 服务层** 与可插拔的 **budgie-shell 展现层**，从而大幅提升多显示器管理、现代窗口贴靠及跨格式应用（Snap/Flatpak/Java）的稳定性与扩展性。通过验证 Ubuntu 官方软件源可知，无论是 26.04 LTS（Resolute）还是开发分支 26.10（Stonking），搭载的仍是 10.10.2 维护版本；由于上游重构工程量庞大且处于早期开发阶段，目前包括 Arch、openSUSE Tumbleweed 在内的各主流发行版均未收录 Budgie 11。
