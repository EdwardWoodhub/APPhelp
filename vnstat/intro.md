# 详细介绍

vnstat 是一款专为 Linux 与 BSD 系统设计的轻量级命令行网络流量监控与持久化统计工具。与需要嗅探数据包或持续重负载轮询的实时监控工具（如 iftop、bandwhich）不同，vnstat 直接读取内核 /proc 或 /sys 接口维护的网络接口统计计数器，因此它几乎不消耗 CPU 与内存资源，且不会对网络吞吐量产生任何性能干扰。它通过后台守护进程（vnstatd）将各网卡的上下行流量数据持久化保存至本地 SQLite 数据库中，即使系统重启或会话断开，历史流量记录依然完整保留。用户可以通过简单的终端指令按分钟、小时、天、月甚至年度维度的聚合视图来查询带宽使用趋势，同时支持导出 JSON/XML 数据或生成基于文本/PNG 的直观统计图表，非常适合用于云服务器（VPS）月度流量配额预警与长期网络带宽审计。
