# 详细介绍

adwaita-icon-theme 是 GNOME 桌面环境的官方默认系统图标主题包，也是 GTK 图形界面生态系统的核心视觉基础组件之一。它遵循 GNOME 人机界面指南（HIG）以及 Freedesktop.org 图标主题规范设计，包含了海量的标准系统图标资源，涵盖文件系统类型、系统设备、应用操作按钮、状态指示器及各种表情符号。该图标主题不仅提供用于传统软件界面与文件管理器的全彩立体风格图标，还包含一套专为现代扁平化工具栏、状态栏及高对比度无障碍模式设计的单色矢量符号图标（Symbolic Icons），能够根据当前 GTK 主题的明暗色彩自动重着色适配。由于 GTK3/GTK4 底层组件高度依赖其中定义的标准图标名称，adwaita-icon-theme 几乎是所有基于 GTK 构建的 Linux 桌面应用程序正常显示界面元素与控制按钮所必备的基础资源包。

几乎所有其他 Linux 桌面环境（如 KDE Plasma、XFCE、Cinnamon、MATE、LXQt 等）以及独立的窗口管理器（如 i3、Sway、Hyprland 等）都可以正常安装和使用 adwaita-icon-theme。
