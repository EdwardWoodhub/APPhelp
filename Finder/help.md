# Copy % Cut

| 操作场景 | 目标效果 | 第一步（键盘操作） | 第二步（粘贴操作） |
| :--- | :--- | :--- | :--- |
| **文本/内容** | 复制副本 | `Command (⌘) + C` | `Command (⌘) + V` |
| **文本/内容** | 剪切移动 | `Command (⌘) + X` | `Command (⌘) + V` |
| **文件/文件夹** | 复制副本 | `Command (⌘) + C` | `Command (⌘) + V` |
| **文件/文件夹** | 剪切移动 | `Command (⌘) + C` | **`Command (⌘) + Option (⌥) + V`** |
